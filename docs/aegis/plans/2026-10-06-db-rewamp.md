# Database rewamp — implementation plan

Date: 2026-10-06.
Spec: `docs/aegis/specs/2026-10-06-db-rewamp-design.md` (rev. 2, **approved**; advisory pass folded in).
Status: **draft rev. 2 — ready for author review before execution.**

## Goal

Land the approved spec end-to-end: split endpoint identity onto psl2
`domain`/`sub_domain` (dropping `host`/`host_type`), move every address into
`endpoint_ip`, replace the ranking law with the binned
`(bin, ⌐weight, domain, sub, addr, endpoint_id)` key served by **one** covering
index, route the page read through a long-lived direct `turso::Connection`, drop
`core_type`/`ConfigType`/`transport_data`/`security_data`, adopt FK cascade, and
prove the result at 74k endpoints — **on turso**, not SQLite.

## Architecture / Tech Stack

Rust 2024, toasty 0.11 + `toasty-driver-turso` 0.11 (turso 0.7.2), ratatui TUI.
New dep: `psl2 = 0.1.31` (idna default). `idna 1.1.0` already in-graph. Owners:
`xray-tui-db` (`models_toasty`, `database`, `profiles_query`, `endpoint_rank`,
`endpoint_ip`, `export`), `xray-tui-proto` (`EndpointEssentials`, `host`),
`xray-tui-config` (`import_export::validate_host`), `xray-tui`
(`state`, `ops/*`, `ui/*`), `xray-tui-core` (`config_builder`).

- No external consumers; the TUI is the only reader.

## Change Necessity

as docs/config. Minimum boundary = the files per task; no new abstraction beyond
the psl2 helper and the `page_reader` module.

## Ripple Signal Triage

Fires (schema, source-of-truth, persistence, producer/consumer, contract).
Canonical owners: `endpoint_rank` owns the ordering key; the psl2 helper +
`state::endpoint_from_essentials` own identity; `import_export::validate_host`
owns the accept rule; `profiles_query`/`page_reader` own the page; `endpoint_ip`
owns addresses; the proto crate (`EndpointEssentials`) owns the parse-boundary
`host`. No fallback/dual owner added — FK cascade *removes* one.

## Plan Pressure Test

Owner fit ✓; higher-level path ✓ (single key + single index); verification scope ✓
(parity + lab); executability ✓. Route: **inline** — S2 is one atomic window
(shared schema prerequisite), so tasks are sequential; S3–S5 are small.

## Ground rule — the S2 non-green window

Dropping a column breaks its readers **in the same statement list/struct**: 
`profiles_query::PAGE_PROJECTION` lists `host`/`host_type`/`core_type`/`config_type`;
`order_terms`/`view_predicate` name `rank_tier`/`rank_latency`; `export.rs`,
`ui/profiles.rs`, `config_builder`, `native_connect` read `host`/`host_type`. So
**S2 tasks T3–T12 will not keep the crate green individually** — the correct cut
is the project's clean-cutover rule (no shims): the schema change and every reader
land **together**, with the wipe. Compile-check each S2 task where it can; run the
workspace suite only at the **S2 boundary** and at each later slice. Do not run the
workspace suite per S2 task — it cannot pass and is not evidence.

## Verification (whole-plan)

- `cargo nextest run --workspace` — Summary line green (not a grep count).
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`.
- `just quality-gate code`.
- `flow_cost` lab at 74k (`XRAY_TUI_SCALE`) and a real-feed measure **on turso**
  via the new reader: Active/Purgatory/All plans show the covering index and no
  temp b-tree; page within the tick budget; per-write cost no regression.
- Identity/validation parity: form path == import path.

## Slice S2 — Atomic model + schema cutover (**one non-green window**; green at the end)

### T3 — psl2 helper + PSL-version meta
**Files:** new helper in `xray-tui-proto` or `xray-tui-config`; `xray-tui-db` for
the meta row; `Cargo.toml` (+ hakari regeneration).
**Change:** ONE split function over `psl2::analyze(host)` returning the normalized
ASCII name + registrable `domain` + `sub_domain` (do NOT call `registrable_domain`
and `subdomain` separately — each normalizes). Add a one-row meta (`psl_version`,
the `rank_weight_meta` pattern) written at open; on a stored-version mismatch, **log
a loud warning** naming the re-import requirement (a PSL change re-keys endpoints; it
is not migratable). Add `psl2 = 0.1.31`.
**Verify:** unit tests — `www.example.co.uk` → (`example.co.uk`,`www`); `github.io`
and `blogspot.com` → `None` (bare suffix) while `foo.github.io`/`foo.blogspot.com`
are registrable; IDN punycode; single-label → `None`. Hakari check green.
**Retire:** n/a.

### T4 — Endpoint model + identity + all-addresses + consumers
**Files:** `crates/xray-tui-db/src/models_toasty.rs`, `endpoint_ip.rs`, `export.rs`,
`crates/xray-tui/src/state.rs` (`endpoint_from_essentials`, `protocol_from_parsed`,
`load_protocol_with_config`), `crates/xray-tui/src/ops/enrich.rs`,
`crates/xray-tui/src/ops/export.rs`, `crates/xray-tui-core/src/config_builder/mod.rs`,
`crates/xray-tui/src/ops/native_connect.rs`.
**Change:** drop `host`/`host_type`; add `domain`/`sub_domain`; identity =
`stable_hash(canonical_name, port)` (dns) / `stable_hash(address_text, port)` (ip) /
`stable_hash("undefined", config_uid)` (exotic); write an IP host's literal as its
`endpoint_ip` row at import; derive host-kind (domain non-empty → dns; else address
row → ip; else undefined). The **proto parse boundary keeps `host`/`host_type`** —
the three `host_type → HostKind` reconstruction sites (`config_builder/mod.rs:67`,
`native_connect.rs:191`, `export.rs:304` + its SQL `:210/:217`) and `ops/export.rs:136`
rebuild `host`/`HostKind` from `domain`+`sub` or the address. `domain`/`sub_domain`
tolerate the empty-host `undefined` case.
**Verify (S2 boundary):** an IP host dials its `endpoint_ip` literal; host-kind derived
matches today's `host_type` for every feed row; an `undefined` endpoint round-trips.
**Retire:** `host`, `host_type` columns; the `HostKind`→`HostType` map.

### T5 — Uniform validation (psl2) + counted skip, form == import
**Files:** `crates/xray-tui-config/src/import_export.rs` (`validate_host`,
`parse_share_url`, `ValidationSettings`), `crates/xray-tui/src/ops/profiles.rs`
(`build_typed_config`), `ops/stream_import.rs`, `ops/subscriptions.rs`.
**Change:** a dns name must yield a psl2 registrable domain, else `ImportError::Validation`;
IP + exotic exempt; the skip is **counted and reported** (never silent); the form
routes through the **same** validator (D9); the parse and row-build use the ONE T3 helper.
**Verify:** tests — single-label/bare-suffix host rejected on both paths (counted);
`foo.github.io` accepted; IP/exotic accepted; a feed with one bad host imports the rest, `skipped=1`.
**Retire:** the form/import divergence.

### T6 — Drop `core_type`
**Files:** `models_toasty.rs` (`ProfileStats.core_type`, `Group.core_type`, `GroupCoreType`),
`database.rs` (`LINK_UPSERT_PREFIX`, `LINK_SOURCE_CONFLICT_SQL`, `core_type_str`, bulk writers),
`profiles_query.rs` (`PAGE_PROJECTION`, `decode_projected_link`), `export.rs`,
`ops/connect.rs`, `ops/profiles.rs` (`resolved_core`, `set_core_field`, form field).
**Change:** remove everywhere; connect derives via `resolve_core(kind, protocol-level
override, ss_method)`. Decide here whether `ProtocolEssentials::write_identity`'s
`core_type` term is dropped → if so bump `IDENTITY_VERSION`.
**Verify (S2 boundary):** connect selects the right core for xray/sing-box/native; gate unchanged.
**Retire:** the `core_type` column + form field + `core_type_str`.

### T7 — Drop `ConfigType` and `transport.data`/`security.data`
**Files:** `models_toasty.rs` (`ConfigType`, `Transport.data`, `Security.data`,
`ProfileStats.config_type`), `database.rs` (upserts, `config_type_str`, `is_unloaded`
guards, `load_protocol_with_config`), `state.rs` (`transport_embed`/`security_embed`),
`profiles_query.rs`, `export.rs`.
**Change:** remove both JSON columns and `ConfigType`/`config_type` (D8/D9).
**Verify (S2 boundary):** protocol upsert/read without the columns; page parity; file
≤ ~95 MB on the 74k re-import.
**Retire:** `ConfigType`, `config_type`, `transport_data`, `security_data`.

### T8 — Ranking law: bins, key, `endpoint_rank` shape, one index
**Files:** `crates/xray-tui-db/src/endpoint_rank.rs` (`RankLink::key`, `compute_rank`,
`write`, `RANK_COLUMNS`, `ensure_in`, band helpers), `models_toasty.rs` (`EndpointRank`).
**Change:** bin function (§3.1); key = `(bin, ⌐weight, domain, sub_domain, addr,
endpoint_id)`; columns = `endpoint_id, rank_bin, rank_weight, rank_domain,
rank_sub_domain, rank_addr, rank_newest_seen, band`; add raw
`endpoint_rank_key(band, rank_bin, rank_weight DESC, rank_domain, rank_sub_domain,
rank_addr, endpoint_id)`; keep `(band, rank_newest_seen)`; drop `test`/`test_v2`/
`band_host`/`window` + retired columns. **`rank_addr`** = the endpoint's own literal
packed key for an IP host (read from `endpoint_ip`, which the refresh already reads
for the dns band `EXISTS`), a sentinel for a DNS host — **not `min(ip_key)`** (that
churns the key on re-resolution). Purgatory = `band=1`.
**Verify (S2 boundary):** Rust `key` vs SQL order parity across the new sorts; a
resolved dns host does NOT move its key; bins place purged/untested/error correctly.
**Retire:** the old tier/latency columns + 3 indexes + `rank_host` etc.

### T9 — Page query: new order/predicate + prefix/IP search
**Files:** `crates/xray-tui-db/src/profiles_query.rs` (`PageSort`→`PageOrder`,
`order_terms`, `view_predicate`, `base_from_where`, `needs_endpoints`).
**Change:** one order — Active `band=0 ORDER BY key`, Purgatory `band=1 ORDER BY key`,
All `1=1 ORDER BY band, key` (**never `band IN (0,1)`**); search = prefix range on
lowercased `domain`/`sub_domain` + an IP/CIDR byte-range on `endpoint_ip.ip_key`;
scope predicate → `rank_bin`.
**Verify (S2 boundary):** `page_order_matches_the_rust_oracle` rewritten; EXPLAIN
shows no temp b-tree for Active/Purgatory/All; an IP term hits `endpoint_ip_by_key`.
**Retire:** the multi-sort `order_terms` branches; the `LIKE '%…%'` search.

### T10 — Delete the sort UI
**Files:** `crates/xray-tui/src/types.rs` (`SortColumn`), `ui/mod.rs` (cycle + key 11
+ `all`), `ops/profiles.rs` (`page_sort`, `set_sort`, `sort_ascending`).
**Change:** single order; remove the sort cycle + state.
**Verify (S2 boundary):** the tab renders the law order; no `sort_column` references.
**Retire:** `SortColumn`; the `s`-cycle handler.

### T11 — Schema tag 15 (wipe)
**Files:** `crates/xray-tui-db/src/database.rs` (`SCHEMA_VERSION`).
**Change:** bump 14 → 15; T3–T10 land together, one recreate. Run **after** all model
changes; do not bump twice.
**Verify:** `open_wipes_a_file_with_a_mismatched_schema_tag` +
`fresh_open_creates_schema_and_sets_user_version_tag`; a fresh re-import succeeds.
**Retire:** n/a (the wipe *is* the migration).

### T12 — FK cascade (fresh-schema DDL + `conn()` pragma)
**Files:** `crates/xray-tui-db/src/database.rs` (`conn()` pragma; the fresh-schema
rebuild hook; `delete_endpoints`, `purge_expired`, `delete_group`, `endpoint_ip::delete_for`).
**Change:** add `PRAGMA foreign_keys=ON` in `conn()` (per-connection — `open()` alone
misses pooled connections, or the cascade is inert); on a **freshly created** schema
(tag-15 recreate; empty tables, cheap) `DROP`+`CREATE … REFERENCES … ON DELETE
CASCADE` the four child tables — SQLite cannot `ALTER`-add a constraint and
`push_schema` emits none; **gate on "schema just created"**, not every open; delete
the manual ordered deletes (one owner).
**Verify:** parity test — cascade deletes exactly the manual set; a cascade fires
**through a pooled connection**; `PRAGMA foreign_key_check` empty after a
re-import/delete cycle.
**Retire:** the manual ordered deletes.
